name: Python 3.12 features on older minimums
description: PEP 695 type aliases and generic syntax, PEP 701 f-strings, itertools.batched, Path.walk, typing.override and other 3.12 APIs used while the declared minimum Python is older than 3.12.

- **Rule**: flag only when the declared minimum (requires-python, `.python-version`, classifiers, CI matrix) is older than 3.12 → SyntaxError or ImportError on that interpreter while newer CI passes. Fix: raise the minimum or use `typing_extensions`/fallbacks.
- **Type parameter syntax (PEP 695)**: `type X = …` aliases and `def f[T](...)`/`class C[T]:` are SyntaxErrors on 3.11. Fix: `TypeVar`/`TypeAlias`.
- **f-strings (PEP 701)**: reusing the enclosing quote inside `{}` (`f"{d["key"]}"`), backslashes or comments in the expression part are SyntaxErrors on 3.11. Fix: the other quote type.
- **3.12 APIs**: `itertools.batched`, `Path.walk`, `typing.override`, `math.sumprod`, `shutil.rmtree(onexc=)`, `NamedTemporaryFile(delete_on_close=)`, `asyncio.eager_task_factory`, `sqlite3.connect(autocommit=)`, `calendar.Month`.
