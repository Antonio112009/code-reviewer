- **Rule**: flag only when the declared minimum (requires-python, `.python-version`, classifiers, CI matrix) is older than 3.10 → SyntaxError, ImportError or TypeError on that interpreter while newer CI passes. Fix: raise the minimum or use a backport.
- **3.10 syntax**: `match`/`case` and parenthesized multi-item `with (a, b):` are SyntaxErrors on 3.9.
- **Runtime `X | Y`**: `isinstance(x, int | str)`, `X | None` in type aliases or in annotations evaluated at runtime (pydantic, dataclass-based libraries, no `from __future__ import annotations`) raise TypeError on 3.9. Fix: `Union[...]`/`Optional[...]`.
- **3.10 APIs**: `zip(strict=True)`, dataclass `kw_only`/`slots`, `itertools.pairwise`, `aiter`/`anext`, `contextlib.aclosing`, `bisect(key=)`, `int.bit_count`, `typing.ParamSpec`/`TypeAlias`/`TypeGuard` (use `typing_extensions`).
- **3.9 APIs (3.8 minimums)**: `str.removeprefix`/`removesuffix`, dict `|`, `zoneinfo` (`backports.zoneinfo`), `graphlib`, `functools.cache`, `asyncio.to_thread`, runtime `list[int]` generics.
