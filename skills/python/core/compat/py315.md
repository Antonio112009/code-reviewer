---
name: Python 3.15 features on older minimums
description: Explicit lazy imports (PEP 810), unpacking in comprehensions (PEP 798), frozendict (PEP 814), sentinel (PEP 661) and math.integer used while the declared minimum Python is older than 3.15.
activation:
  versions: { lang.python: "<3.15" }
  content:
    - "^[ \\t]*lazy\\s+(?:import|from)\\s"
    - "\\[\\s*\\*\\w+\\s+for\\b|\\{\\s*\\*\\*?\\w+\\s+for\\b"
    - "\\b(?:frozendict|sentinel)\\s*\\(|\\bmath\\.integer\\b|\\bprofiling\\.(?:sampling|tracing)\\b"
  examples:
    - 'lazy import polars'
    - 'flat = [*xs for xs in groups]'
    - 'config = frozendict(a=1, b=2)'
sources:
  - https://docs.python.org/3.15/whatsnew/3.15.html
  - https://peps.python.org/pep-0810/
  - https://peps.python.org/pep-0798/
---
- **Rule**: flag only when the declared minimum (requires-python, `.python-version`, classifiers, CI matrix) is older than 3.15 → SyntaxError or NameError on that interpreter while newer CI passes. Fix: raise the minimum or add fallbacks.
- **Syntax**: `lazy import x`/`lazy from x import y` (PEP 810) and unpacking in comprehensions (`[*xs for xs in groups]`, PEP 798) are SyntaxErrors on 3.14. Fix: `__lazy_modules__` (ignored on older versions) or plain imports; `itertools.chain.from_iterable`.
- **New builtins and modules**: `frozendict` (PEP 814), `sentinel` (PEP 661), `math.integer` and the `profiling` package don't exist before 3.15 → NameError/ImportError. Fix: guard on `sys.version_info` or keep a fallback implementation.
