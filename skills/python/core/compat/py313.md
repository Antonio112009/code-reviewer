---
name: Python 3.13 features on older minimums
description: copy.replace, warnings.deprecated, TypeIs/ReadOnly, type-parameter defaults, Queue.shutdown and other 3.13 APIs used while the declared minimum Python is older than 3.13.
activation:
  versions: { lang.python: "<3.13" }
  content:
    - "\\bcopy\\.replace\\s*\\(|\\bwarnings\\.deprecated\\b|\\bfrom\\s+warnings\\s+import\\s[^\\n]{0,60}\\bdeprecated\\b"
    - "\\b(?:TypeIs|ReadOnly|NoDefault)\\b|^[ \\t]*(?:type\\s+\\w+|(?:async\\s+)?(?:def|class)\\s+\\w+)\\[[^\\]\\n]{0,80}="
    - "\\b(?:QueueShutDown|PythonFinalizationError|process_cpu_count|z85encode|z85decode)\\b|\\.shutdown\\s*\\(\\s*immediate\\s*=|\\bbatched\\s*\\([^)\\n]{1,120}\\bstrict\\s*="
sources:
  - https://docs.python.org/3/whatsnew/3.13.html
  - https://peps.python.org/pep-0696/
---
- **Rule**: flag only when the declared minimum (requires-python, `.python-version`, classifiers, CI matrix) is older than 3.13 → SyntaxError, ImportError or AttributeError on that interpreter while newer CI passes. Fix: raise the minimum or use `typing_extensions`/fallbacks.
- **stdlib**: `copy.replace()`, `warnings.deprecated` (PEP 702), `queue.Queue.shutdown()`/`QueueShutDown`, `os.process_cpu_count()`, `itertools.batched(strict=)`, `base64.z85encode`, `PythonFinalizationError` don't exist on 3.12. Fix: `dataclasses.replace`, `typing_extensions.deprecated`, `os.cpu_count`.
- **typing**: `TypeIs` (PEP 742), `ReadOnly` (PEP 705) and `NoDefault` imported from `typing` fail on 3.12; type-parameter defaults (`class C[T = int]`, PEP 696) are a SyntaxError. Fix: `typing_extensions`, `TypeVar(..., default=...)`.
