- **Rule**: flag only when the declared minimum (requires-python, `.python-version`, classifiers, CI matrix) is older than 3.14 → SyntaxError, NameError or ImportError on that interpreter while newer CI passes. Fix: raise the minimum or add fallbacks.
- **Syntax**: t-strings (`t"Hello {name}"`, PEP 750) and `except A, B:` without parentheses (PEP 758) are SyntaxErrors on 3.13. Fix: f-strings/`string.Template`, `except (A, B):`.
- **Deferred annotations (PEP 649)**: unquoted forward references in annotations work lazily on 3.14 but raise NameError at definition time on 3.13. Fix: quote them or use `from __future__ import annotations`.
- **3.14 APIs**: `annotationlib`, `compression.zstd`, `concurrent.interpreters`/`InterpreterPoolExecutor`, `map(strict=)`, `functools.Placeholder`, `uuid.uuid7`, `heapq.heapify_max`, `Path.copy`/`move`, regex `\z` (use `\Z` for older versions).
