---
name: Python 3.11 features on older minimums
description: except*/ExceptionGroup, asyncio.TaskGroup/timeout/Runner, tomllib, StrEnum, datetime.UTC, typing.Self and other 3.11 APIs used while the declared minimum Python is older than 3.11.
activation:
  versions: { lang.python: "<3.11" }
  content:
    - "\\bexcept\\s*\\*|\\b(?:Base)?ExceptionGroup\\b|\\.add_note\\s*\\("
    - "\\bTaskGroup\\b|\\basyncio\\.(?:timeout|timeout_at|Runner)\\b"
    - "\\b(?:tomllib|StrEnum|ReprEnum|file_digest|getLevelNamesMapping)\\b|\\bdatetime\\.UTC\\b|\\bcontextlib\\.chdir\\b|\\boperator\\.call\\b"
    - "\\b(?:Self|LiteralString|Never|assert_never|reveal_type|NotRequired|Required|dataclass_transform)\\b"
  examples:
    - 'except* ValueError as eg:'
    - 'async with asyncio.TaskGroup() as tg:'
    - 'import tomllib'
    - 'def clone(self) -> Self:'
sources:
  - https://docs.python.org/3/whatsnew/3.11.html
---
- **Rule**: flag only when the declared minimum (requires-python, `.python-version`, classifiers, CI matrix) is older than 3.11 → SyntaxError, ImportError or AttributeError on that interpreter while newer CI passes. Fix: raise the minimum or use a backport.
- **Exception groups**: `except*` is a SyntaxError on 3.10; `ExceptionGroup`/`BaseExceptionGroup` and `add_note()` don't exist. Fix: the `exceptiongroup` backport.
- **asyncio**: `asyncio.TaskGroup`, `asyncio.timeout()`/`timeout_at()` and `asyncio.Runner` are missing on 3.10. Fix: `taskgroup`/`async-timeout` backports or AnyIO.
- **stdlib**: `tomllib` (use `tomli`), `enum.StrEnum`/`ReprEnum`, `datetime.UTC`, `hashlib.file_digest`, `contextlib.chdir`, `operator.call`, `logging.getLevelNamesMapping`.
- **typing**: `Self`, `LiteralString`, `Never`, `assert_never`, `reveal_type`, `Required`/`NotRequired`, `dataclass_transform` imported from `typing` fail on 3.10. Fix: import them from `typing_extensions`.
